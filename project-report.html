QQ群消息监控 v1.0

面向学生群体的QQ群消息实时监控系统  |  开源协议：MIT  |  2026年5月

项目定位

老师在QQ群布置作业或发布考试通知时，系统通过截图OCR、UI Automation或OneBot WebSocket 三种模式实时采集群聊消息，匹配用户设定的关键词后即时桌面弹窗提醒，避免错过重要信息。 配套Web管理面板提供消息记录浏览、关键词管理、数据可视化看板及CSV导出功能。

三种采集模式对比

模式原理QQ窗口要求延迟推荐场景
截图+OCR MSS截屏 → PaddleOCR → 文本匹配 QQ需可见 2-5秒 通用场景，兼容性最好
UIA后台 UI Automation直接提取窗口文本 QQ可最小化 0.5-2秒 后台静默运行
OneBot WS 对接NapCatQQ WebSocket事件流 无需窗口 <0.5秒 零延迟，最推荐

安全措施

措施实现
密码存储bcrypt 加盐哈希 (cost factor=12)
会话安全Flask Session + 环境变量 QQ_MONITOR_SECRET 签名密钥
SQL注入防护全部使用参数化查询 (SQLite placeholders)
登录保护用户名≥2字符，密码≥3字符，Session登录态校验
部署安全Docker容器隔离，推荐Nginx反向代理 + HTTPS
